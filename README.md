# ViettelConnect

Community .NET SDK cho dịch vụ chữ ký số từ xa **Viettel MySign** (`ViettelConnect.MySign`): ký mã băm SHA256, người ký duyệt từng yêu cầu trên ứng dụng MySign.

> **Chưa phát hành.** Chưa có gói trên nuget.org; API công khai chưa ổn định và chưa được kiểm chứng với tài khoản MySign thật.
